# ADR-0006: Hosting on GitHub

- Status: proposed (details in ../plan/hosting.md)

## Decision
GitHub, first as a **private repo `its-sven/gigcraft`**, public once the first usable version exists. Later, if contributors join, transfer to a GitHub organisation (the name `gigcraft` is taken by a user account; e.g. `gigcraft-app`). GitHub keeps redirects after a transfer.

## Why GitHub
ArtCraft and craft-libs live on GitHub and ArtCraft Launcher installs from GitHub releases; Actions offer macOS runners for iOS builds; Sven's other open-source projects (Tasks Board, Cuebook) are there.
